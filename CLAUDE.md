This project, notebooks, is meant to act as a collection of ideas or mini-projects that aren't large enough in scope to warrant their own dedicated repository. I organize my random ideas into their own subfolders. Each time we discuss a new idea, you should create a folder in this repo to hold all of the related files. We use a single shared env for everything. Testing is not required unless specified. Code is like a scratchpad to achieve the results we want, its not the final product itself.
